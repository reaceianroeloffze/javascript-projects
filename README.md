## Projects

### [Random Background Colour Generator](https://github.com/reaceianroeloffze/javascript-projects-portfolio/tree/Root/random-background-colour-generator)

In this project, I created a random colour generator that generates a random colour every time the user clicks the button.
The colour is then displayed in the background of the page.
The colour is also displayed in the text box in hexadecimal format. 
As the colour is generated, the text box is updated with the new colour.
